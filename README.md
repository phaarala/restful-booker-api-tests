# Restful Booker API - Postman Tests

A Postman collection of automated API tests against the public [Restful Booker] (https://restful-booker.herokuapp.com/) practice API, version-controlled via Postman's Git integration.

**Coverage:** reading all bookings (GET), reading a single booking (GET), and creating a booking (POST). Collection-level tests assert the response status code (200) and response time (<500ms) on every request.

**To run:** import the collection into Postman and run it (or use the Collection Runner).
